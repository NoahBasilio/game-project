# Avoid the Orbs! 

A minimalist, fast-paced survival game built with Python and Pygame-CE. (And my first ever Pygame project!)

## Gameplay
The goal in my game: **Survive as long as possible!!!** <br><br>
Orbs will spawn from the edges of the screen and drift toward the center. Use your mouse to navigate the play area and avoid colliding with any of the drifting orbs.

- **Controls:** Mouse movement.
- **Objective:** Avoid all orbs.
- **Game Over:** If an orb touches your cursor, the game ends.

## Installation & Setup

### Prerequisites
- Python 3.x
- Pygame library

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/NoahBasilio/game-project/
   cd game-project

2. Install dependencies:
    ```bash
   pip install -r requirements.txt
    ```
### Running the Game

python main.py
